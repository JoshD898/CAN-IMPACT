# USe the REDCap API to load a raw export

USe the REDCap API to load a raw export

## Usage

``` r
from_api(token, save_path = NULL)
```

## Arguments

- token:

  API token to use

- save_path:

  Path to save the export to (must end in .csv). Default is \`NULL\`.

## Value

A data frame of the raw export data
